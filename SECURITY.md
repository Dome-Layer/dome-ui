# Security

## Reporting vulnerabilities

If you discover a security vulnerability in any Dome project, please email **security@domelayer.com**. Do not open a public issue.

## Secrets policy

This repository contains **no secrets**. All sensitive values (API keys, service-role keys, signing secrets) are stored exclusively in deployment platform environment variables (Vercel, Railway) and are never committed to source control.

## Key inventory

This package has no runtime secrets. It is a client-side library that reads/writes browser cookies and renders React components.

## Rotation history

Not applicable — no secrets to rotate.
